# Event website template

For weddings, parties, launches, reunions and conferences. The names, the date and the venue on the first screen, then the story, the schedule, how to get there and where to stay, photographs, questions, and an RSVP form with party size and dietary needs. Structured data describes the event with its place and dates.

[![Deploy to Statpio](https://img.shields.io/badge/Deploy%20to-Statpio-f39200?style=for-the-badge)](https://statpio.com/new?template=event)

Live preview: https://statpio.com/templates/event/preview · Template page: https://statpio.com/templates/event

## What is in it

- One page, plain HTML and CSS: no framework, no build step, no scripts, nothing loaded from a third party.
- Sections: Hero, The story, Schedule, Venue and travel, Photographs, Questions, RSVP.
- A rsvp form that posts to the page's own address (on Statpio the messages land in your inbox; elsewhere point it at a form backend).
- Structured data (Event and FAQPage), Open Graph tags, a canonical address, robots.txt, sitemap.xml, an llms.txt for AI assistants, a 404 page, a favicon and a web manifest.
- Its own fonts, self-hosted: cormorant garamond and jost (Google Fonts, SIL Open Font License, see fonts/OFL.txt).

## Use it

**On Statpio (free):** press the button above. The site goes live at your-name.onstatpio.com within seconds with the form working, and the Site content page lets you replace the demo texts and photos without touching the code.

**Anywhere else:** download or clone this repository and upload the folder to any static host. Edit index.html in a text editor; the colours are the `--primary` and `--accent` variables at the top of styles.css.
